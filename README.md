A fortune cookie message for a software engineer, written as a single line of at most 120 characters. The program writes the line to `entry.txt` in the output directory.

## The entry

> Beware the flaky test that passes locally, fails on CI, and waits for your demo.

(80 characters, one line.)

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node --experimental-strip-types main.ts
```

This writes `output/entry.txt` containing the fortune above. It writes only under the output directory, so it also runs with the repository mounted read-only.
